# Exploring WordPress Customization

## Activity Description
This activity explores how to customize a WordPress website using themes and plugins.

## Themes
I selected Astra theme because it has a clean design and offers different customization options. It allows me to change the appereance and layout of my website.

## Plugins
I selected WPForms Lite because it allows me to create contact forms for my website. This makes it easier for visitors to communicate with the website owner.

## What I Learned
I learned how to install and activate WordPress themes and plugins. I also learned how these tools can improve the appeareance and functionality of a website.
